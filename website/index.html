Quick Guide

Ready in
5 steps

Install the App

Windows: Run Ovilo-0.1.0-Setup.exe and follow the wizard. Linux: Install via .deb, .rpm, AppImage, or extract ovilo-0.1.0-linux-x86_64.tar.gz and run ./install.sh. Android: Install ovilo.apk directly.

Create Your Account or Continue as Guest

Sign up to sync your favorites, watch history, and themes across devices, or start right away as a guest.

Watch Cinema & Series

Browse top streaming titles, choose your server, and resume any episode with 1080p high fidelity.

Stream Music with Synced Lyrics

Play your tracks with synchronized karaoke lyrics that scroll automatically in time with the song.

Download Media

Paste any supported video link into the Downloads tab, or connect to your local media servers.

Frequently Asked Questions

Windows says “unknown publisher”

Click “More info”, then “Run anyway”. This shows for newly released open-source builds without a paid commercial certificate.

The AppImage won’t open on Linux

Ensure executable permissions are set: chmod +x ovilo-*.AppImage. If needed on Ubuntu 22.04+, install fuse: sudo apt install libfuse2.

Can I delete or uninstall cleanly?

Yes. On Windows, use Settings → Apps or the uninstaller. On Linux tarball, run ./uninstall.sh to remove shortcuts and binaries cleanly.
